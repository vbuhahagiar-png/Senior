# Assets visuels requis

## Images obligatoires
- `splash.png` — Écran de démarrage (1242×2688 px recommandé, fond #F5F0E8)
- `icon.png` — Icône app (1024×1024 px)
- `adaptive-icon.png` — Icône adaptive Android (1024×1024 px)
- `favicon.png` — Favicon web (64×64 px)

- Sauge : #8A9E85
